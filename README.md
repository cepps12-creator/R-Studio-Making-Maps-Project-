# U.S. Income Geographic Data Visualization (R Spatial Analysis Project)
Conducted a spatial data analysis of U.S. income distribution using R and simple features (sf) data structures to explore geographic variation across states. Joined U.S. income data to spatial state boundaries using left_join() and developed a series of choropleth maps to visualize income patterns across the United States.

The project focused on effective data visualization design, comparing gradient, classed, sequential, and diverging color schemes to evaluate how visual encoding choices impact interpretation of geographic inequality. Generated both continuous and categorical thematic maps and analyzed how different classification methods alter the perception of regional income disparities.

Applied best practices in data visualization and accessibility by evaluating maps using the colorblindr package and testing alternative palettes such as the Okabe-Ito color scheme to improve readability for users with color vision deficiencies. Emphasized clear storytelling through spatial data, demonstrating how income varies across regions and how visualization choices influence policy interpretation.

# Key Insight
Income distribution across the United States shows strong regional clustering, and the way data is visually encoded (gradient vs classed or sequential vs diverging schemes) significantly affects how patterns of inequality are perceived and interpreted.
